# Security Policy

mascot-forge is a build-time tool and a dependency-free static editor; it ships no server and no runtime
dependencies, so the attack surface is small. Still, if you find a security issue, please report it.

## Reporting a vulnerability

- **Preferred:** open a [private security advisory](https://github.com/rockhoppa123/mascot-forge/security/advisories/new)
  on this repository.
- **Or:** email **andrew@dataweb.co.za** with details and steps to reproduce.

Please do not open a public issue for an undisclosed vulnerability.

## Scope & expectations

This is a solo, open-source project maintained on a best-effort basis — there is no formal SLA. I will
acknowledge reports as soon as I reasonably can and credit reporters who wish to be named.

## Supported versions

The latest tagged release and `main` are supported. Older tags are not patched.
