# ADR-0004 — MIT license, portfolio-first (no monetisation in this phase)

- **Status:** Accepted
- **Date:** 2026-06-17

## Context
The author weighed "open source for career signal" against "maybe sell it later."
Source-available licences (BSL/PolyForm) protect a future business but cost community
goodwill, stars, and contributor trust — heavy machinery for an unproven v1. The primary,
stated goal is a credible portfolio piece.

## Decision
License the project **MIT**, fully open, with **no monetisation plan** in this phase.
Optimise for clarity, stars, and career signal.

## Consequences
- Maximum reuse and contribution; strongest portfolio story.
- All dependencies must be permissive/MIT-compatible (VTracer MIT ✓, GSAP free ✓).
- If a business case appears later, an open-core model (paid hosted GUI / pro emitters)
  remains possible *on top of* the MIT core without relicensing it. Revisit only with
  evidence of demand.
